# قِوام / FitCore — موقع واحد من تصدير Stitch

`index.html` ملف واحد يشتغل بفتحه مباشرة (بدون سيرفر وبدون إنترنت — CSS مبني داخله).
`artifact.html` نفس الموقع بدون وسوم html/head/body، للنشر كـ Artifact.

## وش صار للشاشات

٢٤ شاشة من تصدير Stitch + شاشة «حسابي» مضافة = ٢٥ شاشة في ملف واحد:

- كل شاشة صارت `<section data-screen="…">` وتظهر وحدة بس.
- شريط علوي **واحد** لكل الشاشات: شعار FitCore + عنوان الشاشة + زر رجوع + اللغة + المظهر + كل الشاشات.
- شريط سفلي **واحد**: الرئيسية · الوجبات · (+) · التمارين · التقدّم.
- الهيدر والفوتر الأصليين لكل شاشة مخفيين بـ CSS (ما انحذفوا من المصدر).

## المظهر النهاري والليلي

ألوان Stitch الـ٤٧ تحوّلت من قيم ثابتة إلى متغيّرات CSS:
`"surface": "rgb(var(--c-surface) / <alpha-value>)"` — وفيه لوحة داكنة (الأصلية) ولوحة
فاتحة مقابلة. زر المظهر يبدّل `html.light` فتتغيّر كل الشاشات دفعة وحدة، وتنحفظ الحالة.

## اللغة

زر `EN/AR` يقلب `dir` و`lang` ويترجم النصوص عبر قاموس في `i18n.json`.
المترجم يمشي على عقد النص ويحتفظ بالأصل، فالرجوع للعربي كامل بدون فقدان.
القاموس يغطي واجهة التطبيق والمصطلحات المتكررة — النصوص الطويلة الخاصة بكل شاشة
تحتاج ترجمة إضافية تُضاف لنفس الملف.

## بياناتك تمشي في الشاشات

حقول التسجيل والتهيئة مربوطة تلقائياً (`labelFor` يقرأ النص الملاصق للحقل):
الاسم، البريد، الهدف، العمر، الطول، الوزن، الوزن المستهدف، سرعة التغيير.
منها تُحسب السعرات بمعادلة Mifflin-St Jeor وتوزيع الماكروز، وتُحقن في كل شاشة
(الرقم الثابت ١٩٥٠ يصير هدفك أنت، و«فهد» يصير اسمك).
