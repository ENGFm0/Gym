# FitCore — ملفات الشعار

كلها **خلفية شفافة**، ما فيها أي سواد محروق، وما تحتاج `mix-blend-mode`.

| الملف | متى تستخدمه |
|---|---|
| `fitcore-logo.svg` | الشعار الكامل على خلفية **داكنة** (حروف بيضاء + ليموني `#C4F34D`) |
| `fitcore-logo-dark.svg` | الشعار الكامل على خلفية **فاتحة** (حروف `#101512` + ليموني غامق `#6E9E12`) |
| `fitcore-mark.svg` | العلامة الدائرية وحدها — أيقونة التطبيق والفافيكون على داكن |
| `fitcore-mark-dark.svg` | العلامة الدائرية على فاتح، أو داخل مربع ليموني |
| `*.png` | نفس الملفات كـ PNG شفاف (الشعار ٢٠٤٨px، العلامة ٥١٢px) لأي أداة ما تقبل SVG |

الحروف محوّلة إلى **مسارات vector**، فما يحتاج تحميل خط ولا يتغيّر شكله على أي جهاز.

## الاستخدام

```html
<img src="/brand/fitcore-logo.svg" alt="FitCore" style="height:28px;width:auto">
```

لا تضعه داخل مربع أو بطاقة، ولا تستخدم `filter` أو `invert` أو `mix-blend-mode` —
الخلفية تمر من خلفه مباشرة. على الخلفيات الفاتحة بدّل الملف إلى `fitcore-logo-dark.svg`.
